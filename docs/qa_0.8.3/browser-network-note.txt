Próba bezpośredniej nawigacji Playwright/Chromium do lokalnego serwera HTTP w tym środowisku zakończyła się błędem net::ERR_BLOCKED_BY_ADMINISTRATOR. Nie uzyskano tą drogą wyniku testu aplikacji. Test UI tools/browser_083_smoke.py ładuje rzeczywiste pliki HTML/JS/CSS do DOM i używa kontrolowanego mostu Python WebSocket do rzeczywistego serwera. localStorage jest testowym obiektem w pamięci. Native HTTP/WS przeglądarki, utrzymanie localStorage między uruchomieniami i urządzenia fizyczne pozostają niezweryfikowane. Niezależne testy Python/aiohttp weryfikują HTTP i rzeczywiste połączenia WebSocket serwera.

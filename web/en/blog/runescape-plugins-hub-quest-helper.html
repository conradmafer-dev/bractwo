RuneScape Plugin Hub: how to install plugins and use Quest Helper

Bractwo Krain TeamPublished: 20 October 2026English version: 20 October 20265 min read

The official RuneScape Plugin Hub launched on 19 October 2026. Its first five community-made tools include Quest Helper, with support for 69 quests. Here is how to find the Hub, choose a useful plugin and understand its limits before reorganising your interface.

Live release, not a beta access guide. This article concerns RuneScape, often called RS3. Old School RuneScape and RuneLite are separate. Our earlier plugin beta article preserves the announcement before testing; the installation steps below concern the official release.

Still choosing a game? Read our RuneScape 3 vs Old School RuneScape comparison and getting-started guide.

How to install RuneScape plugins

Open the toolbox icon on the Ribbon, normally near the bottom-right of the screen. In the classic interface it appears by default. On the default modern Ribbon, hover over Settings; if you use a custom Ribbon without room for the icon, edit the Ribbon and add it.

  1. Open the RS Plugin Hub and choose a plugin.
  2. Complete the required email verification for the hosting service, mod.io. Jagex recommends your Jagex Account email, although another email can be used.
  3. Install the plugin. If it needs permission approval, open Manage, review the request and enable it there.

The same Hub lets you manage and uninstall tools. Its plugins run inside the game; they do not provide separate windows outside the client.

Our suggested first test: install one tool for something you are already doing. Try a supported quest or a familiar route, then decide whether the change helps. Adding everything immediately makes it harder to identify which setting caused an unwanted overlay or changed interaction.

How to start Quest Helper

The official plugin breakdown explains that supported quests have an asterisk in the Quest panel. Right-click one of these to use Quest Helper. Its purpose is to follow your quest progress and direct you towards the next step. The launch count of 69 is a coverage snapshot, not a promise to support every quest.

For a returning player, a sensible test is a quest you want to complete rather than one chosen only because a helper exists. Read the dialogue if the story matters to you; assistance with finding the next objective need not turn the whole adventure into a checklist. If guidance appears inconsistent, compare it with the quest journal before spending time repeating a route.

The distinction from the beta matters here. The October test used separate worlds whose progress did not carry over. Do not follow old beta-world launch instructions when your aim is to use the released Hub in your normal game.

What do the other four launch plugins do?

  • Menu Entry Swapper reorders interaction-menu options. Use it to adjust permitted repeated interactions.
  • Tilemarkers records manually chosen locations. Hold Ctrl + Shift and right-click a tile to mark it; repeat on a marked tile to customise it.
  • Entity Hider hides selected kinds of characters or creatures from view.
  • Job Gauges brings combat resources and cooldown information into combat-style overlays.

Our practical approach: choose according to the problem. If you forget a position you have already learned, a manual marker gives it a visible reminder. If your screen is crowded, try hiding one category before making broader changes. With combat overlays, keep the information you actually act on easy to locate rather than filling every available space.

Why RuneScape plugins do not work exactly like RuneLite

The API controls what each tool can access. At launch, Menu Entry Swapper cannot make Teleport or Drop the default left-click action for items, or provide Buy All in shops. An unavailable option therefore need not mean that you installed it incorrectly.

The official plugin guidelines allow clarity and organisation tools but prohibit automated player actions and replacing player skill or decision-making. Manually marking a tile and automatically predicting a safe position are different capabilities. A helper is not permission to use a bot.

Clue Trainer and Ground Items were awaiting moderation in the launch announcement. They should not be treated as part of the five-plugin release. For later additions, check the current in-game catalogue rather than assuming a plugin mentioned in an older preview is available.

Where to report a plugin problem

Check the plugin's mod.io page, linked from the Hub, for its developer's preferred feedback channel. For the Hub itself, use the game's bug-reporting option or the official RS Plugin Discord. Describe the action, the expected result and what happened; include which plugin was enabled so that another person can reproduce it.

Community creators maintain the tools, while Jagex reviews submissions. The submission documentation also requires descriptions of requested permissions and data use. Reading those explanations is useful when deciding whether a tool fits your needs. A larger catalogue is less valuable than a few tools you understand and can turn off when you no longer need them.

If you are interested in making a plugin, start with Jagex's API documentation and Lua tutorial. For more developments in the game, see our RuneScape 2027 roadmap overview.
